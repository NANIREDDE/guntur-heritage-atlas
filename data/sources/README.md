# Sources

Store metadata about evidence used by heritage records.

Recommended fields:

- `source_id`
- `title`
- `author_or_organization`
- `publication_year`
- `source_type`
- `url_or_archive_reference`
- `page_or_section`
- `access_date`
- `notes`
- `reliability_notes`

A source record identifies where a claim came from; it does not automatically make the claim true. Conflicting sources should be retained and described rather than silently merged.
